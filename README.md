# Blockchain for Information Assurance: A Systematic Review of Security, Privacy, and Trust

This repository contains:
- Blockchain_Information_Assurance_Review.docx — IEEE-formatted two-column manuscript
- Blockchain_Information_Assurance_Review.pdf — PDF export
- references.bib — BibTeX file for all references
- paper.md — Source manuscript in Markdown

## How to cite
M. U. Rehman, “Blockchain for Information Assurance: A Systematic Review of Security, Privacy, and Trust,” 2025.

## Notes
- The Word document follows IEEE template conventions (two columns, abstract, keywords, numbered sections, and IEEE-style references with DOIs/URLs).
- The PDF is generated from the Word source/Markdown.

## Build
A GitHub Actions workflow builds PDF and DOCX from paper.md on each push to the ieee-artifacts branch.
